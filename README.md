# NS — Nouveau Secondaire study app (Ionic)

A mobile app for Haitian students in the **Nouveau Secondaire (NS4)** program, with pages for each track:
**SES**, **SLLA**, **SMP** and **SVT** (ses1–4, slla1–4, smp1–4, svt1–4), plus settings and app info.
Built with **Ionic / Angular / Cordova**. Firebase web app "NS" was set up for it.
